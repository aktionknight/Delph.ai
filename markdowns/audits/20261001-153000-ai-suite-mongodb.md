# Scoped review: AI suite and MongoDB runtime

Parent revision: `eba626b44542bc24e3435d7a91ebc67419a18bd8`. Review of this working change, not an exhaustive security audit.

## Findings, evidence and mitigations

| Severity | Finding / evidence | Mitigation and remaining work |
| --- | --- | --- |
| High deployment blocker | No live provider credentials or Mongo replica-set endpoint were supplied. Automated Mongo tests use an in-memory transactional contract implementation. | Actual credentialed generation, Atlas transaction/write-conflict behavior and binary storage must be verified before public deployment. Offline tests do not establish provider availability or factual quality. |
| Medium | `auth.py` implements local password accounts with scrypt salts and opaque HttpOnly sessions, but email verification, recovery, MFA and centralized abuse controls are absent. `COOKIE_SECURE=false` in the example supports local HTTP. | HTTPS plus `COOKIE_SECURE=true` is required in deployment. Add verified-email/recovery or hosted auth and central per-user/IP quotas before wider use. Keys/password hashes are not returned to the browser. |
| Medium | `jobs.py` executes in-process background tasks. Process termination interrupts execution; inactivity timeout exposes failure but cannot guarantee cancellation or exactly-once provider calls. | Mongo unique active-job index limits concurrent background jobs; campaign revisions/transactions reject stale final writes. Reload after stream loss. Adopt a durable queue, heartbeat/recovery and fencing tokens for distributed deployment. Direct synchronous endpoints remain available. |
| Medium | LLM output, embeddings, reranking and factual evaluations remain probabilistic. System prompts instruct models to treat source text as untrusted data, but this cannot eliminate prompt injection. | Pydantic contracts, citation validation, source exclusion, safety/format checks, bounded one-pass repair and explicit version approval fail closed. Media review is explicitly human; no automatic claim of visual/audio correctness. Run a real provider-backed adversarial quality set. |
| Medium | `storage.py` writes R2/GridFS binaries separately from aggregate transactions; failure cleanup is best-effort. Deleting retrieval sources leaves original objects stored. | Private owner-key routing, authenticated download endpoints, random object IDs and bounded binary uploads mitigate exposure. Implement object lifecycle/retention and orphan reconciliation. Avoid public bucket policies. |
| Medium | Brand sources and asset history are embedded aggregates. Retrieval is a bounded scan; large histories can grow to Mongo's document limit. Source API/export includes embeddings for the owning user. | Source-text limits and a 15 MiB BSON capacity check prevent oversized writes without deleting history. Split histories/chunks into indexed collections and use native vector search for scale. Reduce public response payloads in a subsequent optimization. |
| Medium | Provider API availability, free quotas and usage rights change. Listed Gemini 2.0 and Groq Llama defaults are retired, Pollinations uses keys, Edge TTS is unofficial. | Configurable per-role providers/models, safe errors without secret-bearing upstream response bodies, optional features and current documentation links. Verify account access/costs; no unconditional free or latency promise. |
| Low | Analytics imports are user-attested, not fetched from a platform. Overlapping experiment/date ranges can double-count exposures. | Evidence reference and cumulative snapshot history are recorded; source labels disclose manual data. AI experiments start at zero; demo numbers remain labeled. Add authenticated platform ingestion and metric deduplication before reporting production results. |
| Low | Browser visual QA was unavailable because browser bootstrap rejected missing sandbox metadata. | Frontend typecheck/build pass. Check registration, profile editing, job progress, planning forms, import forms and media review visually when browser tooling/credentials are available. |

## Verified protections and regressions

- Original demo golden path, PDF/text limits, restart persistence, platform validators, immutable revisions, current-guardrail enforcement and stale approval rejection remain covered by 11 original tests.
- New tests verify private owner reads/writes, hashed passwords, cookie properties, expiry/logout, profile editing, transaction rollback/revision conflicts, malformed/truncated model output, safe credential handling in provider headers, semantic failure/repair history, live job progress, imported metrics, unapproved variant promotion and explicit media review.
- Optional adapter tests validate Cohere indices, R2 private owner routing and Pollinations missing-key behavior. These use controlled responses, not live services.
- 20 backend tests pass; 12 commit-documentation tests pass after Windows subprocess permission was granted. Typecheck and final production build pass, including final UI additions. Working diff whitespace check passes.
- No user-owned `markdowns/globals` changes, credentials, generated dependencies, or Git commit are introduced by this task. Hook configuration was installed with approval.

## Tests not run / remaining implementation

Live Gemini/Groq structured outputs and semantic quality, embedding/model dimensional compatibility, real Atlas isolation/retries, GridFS and R2 live persistence, Pollinations billing/access, Edge service availability, full browser workflows and deployment smoke checks were not run. Add centralized monitoring/rate limits, recovery/verified auth, distributed jobs, social OAuth/posting and analytics, OCR/video, object cleanup and provider-backed quality evaluations before treating the MVP as a production service.
